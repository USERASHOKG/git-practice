# git-practice
Practising Git commands using GitHub Codespaces


Task	        Command
Clone a repository	git clone <repo-url>
Create a branch	git checkout -b feature/my-fix
Check status	git status
Stage changes	git add .
Commit changes	git commit -m "message"
Push a branch	git push -u origin feature/my-fix
Switch branches	git checkout main
Pull latest changes	git pull origin main
View commit history	git log --oneline
View remotes	git remote -v
